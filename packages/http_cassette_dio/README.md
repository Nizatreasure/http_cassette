# http_cassette_dio

`http_cassette_dio` is the planned Dio integration for HTTP Cassette. It will
translate Dio traffic for the transport-neutral `http_cassette` package.

This release is a scaffold only. The Dio adapter is not implemented, and the
package exposes no public API.

## Installation

The package is not ready for use or publication. During development in this
workspace, it can be resolved with `dart pub get` from the repository root.

## Example

The example is intentionally an empty compile check because no adapter API has
been implemented.

```sh
dart run example/http_cassette_dio_example.dart
```
